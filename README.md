# Arenne Skin — static skincare storefront

A framework-free HTML5/CSS3/JavaScript storefront with 17 public page templates, 24 centralized product records, combined catalog filters, reusable inline skin finder, bundle pricing, a LocalStorage mini-cart, checkout preview, consultation form validation, dark mode and RTL layout support.

## Run locally

From this directory:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/`. The root entry redirects to `pages/index.html`.

## Important launch notes

- `Arenne Skin` is an editable working identity because no final business name was supplied.
- Product names, packaging associations, directions and prices are demonstration content. Verify final product facts and replace stock editorial imagery with exact authorized packshots before commerce launch.
- The consultation form validates locally but does not send data until a provider is configured.
- Checkout does not accept payment or place orders.
- Legal, shipping and returns pages are structures to customize, not final policies.

See the `documentation/` directory for detailed implementation guidance.
