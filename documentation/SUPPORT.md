# Support and handoff

Before production launch, supply the final legal business name, support email, verified products and formulas, authorized exact product photographs, final pricing, availability, shipping/returns terms, form provider and payment provider.

For implementation issues, reproduce the problem through a local HTTP server and include the page URL, viewport width, browser version and console error. Run `node tests/qa.mjs` to check the required architecture, product count and local file references.
